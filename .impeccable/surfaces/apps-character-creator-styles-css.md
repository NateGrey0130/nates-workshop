## Direction contract

THESIS: The sheet is a stack of end labels, read by their faces. A section is a
box you slide half out; the one you are working in is physically forward of the
others. This refuses the dark panel-of-cards arrangement the RPG suite has run
since Rust & Ash, and refuses the bright-parchment answer that "not dark" usually
produces.

OWN-WORLD: Board orange (#C7541F) owns whole regions — headers, rails, the tab
bar — rather than trimming a neutral one. Content sits on tissue white (#FAFAF8)
inside #FFFFFF blocks. A 13px chip column down each block's left edge is that
section's colour (#1A1614 ink, #E8DCCB tissue, #2E6F5E green). Ink #1A1614,
rules #DED6CB. No radius; no shadow. Barlow Condensed at label scale for names
and controls, Martian Mono for every run of figures. Night: ground #191513,
board raised to #F06B2A, panels #23201D, ink #F2EDE7.

STORY: The player sees which section is live before reading a word, finds the
number they need in one sweep, and presses one thing.

FIRST VIEWPORT: Full-width orange band, character name in Barlow Condensed 700
at 66px caps, mono identity line beneath, colourway chips right. Below it three
blocks in a row on tissue: Attributes (316px), Pools (372px, pulled 14px proud
top and bottom with an orange chip and border), Invocations (fills). Primary
action is the Cast button in each invocation row; the P.P.E. steppers sit at
44px inside the pulled-out block. Orange tab bar closes the page.

FORM: Sneaker box stacks (textiles-weave-drape-fashion-sneaker-box-stacks),
challenger 6 of round one's hand; seed key f80e6e9b. Not the assigned direction
and not the pick — user-pinned after seeing the hand, which beats the roll.

RAISES CARRIED IN: state is a mark, not a hue (donor: cutting-bench select rail)
— every state reads as a mark first, colour only confirms. Pinned annotation
(donor: centre-rail reference setting) — a grant's stored `reason` hangs in a
margin bracketed back to the number it changed. Pool states beyond the number
(donor: tensegrity column) — rested, spent, at the limit.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance.
